# Neon Escape

3D-Top-down-Shooter, entwickelt im Team mit Unity und C#.

## Windows-Download

1. Lade `Neon-Escape-Windows.zip` herunter.
2. Entpacke die Datei vollständig.
3. Starte `NeonEscape.exe`.

Die ZIP-Datei enthält den spielbaren Windows-Build inklusive der benötigten Unity-Dateien.

## Technologien

- Unity
- C#
- 3D-Game-Development
